# Sōma — Contemporary Indian Kitchen

Sōma is a full-stack restaurant web application built around the idea of combining contemporary Indian dining with a modern digital experience.

The application includes a dynamic menu powered by MongoDB, an online reservation system, an admin dashboard for restaurant management, and an AI-powered food recommendation system.

## Features

### Customer Website

- Modern responsive restaurant website
- Contemporary Indian restaurant branding
- Responsive navigation with mobile menu
- Hero section with restaurant introduction
- Dynamic menu loaded from MongoDB
- Menu category filtering
- Vegetarian and spice-level indicators
- Featured dish highlighting
- Interactive menu cards
- Scroll-based reveal animations
- Restaurant story page
- Visit and contact page
- Reservation form
- Reservation time-slot selection
- Reservation capacity validation
- Responsive design for desktop, tablet, and mobile
